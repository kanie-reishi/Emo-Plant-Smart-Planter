Kế hoạch Triển khai AI Model - Smart Planter AI

Dựa trên tài liệu đặc tả hệ thống và mã nguồn hiện có, dưới đây là kế hoạch chi tiết để thay thế Mock Model bằng AI Model thực tế (MobileNetV2 huấn luyện trên tập PlantVillage).

Thông tin phần cứng & dữ liệu (Cập nhật từ phản hồi của bạn):
  • Dữ liệu PlantVillage: Dung lượng tải về dự kiến khoảng 800MB (file nén) và sau khi giải nén sẽ chiếm khoảng 1.5GB - 2GB dung lượng ổ cứng.
  • Phần cứng: Sử dụng GPU RTX 3050 (sẽ giúp tăng tốc độ huấn luyện lên đáng kể nhờ CUDA so với CPU, cấu hình này đủ để train MobileNetV2).
  • Độ trễ (Latency): Chưa cần tối ưu UX ở giai đoạn này.
Chiến lược Transfer Learning cho Cây Cảnh (Indoor Plants):

Mục tiêu của dự án là nhận diện sức khỏe cây cảnh, nhưng ta sẽ dùng phương pháp Học chuyển giao 2 giai đoạn:

  1. Giai đoạn 1 (Pre-training): Huấn luyện model trên tập PlantVillage (cây nông nghiệp) để học các đặc trưng thị giác cơ bản của lá cây và vết bệnh.
  2. Giai đoạn 2 (Fine-tuning): Dùng một tập dữ liệu nhỏ chuyên về cây cảnh (Monstera, Trầu bà...) có các biểu hiện stress để tinh chỉnh lại mô hình.

1. Chuẩn bị Dữ liệu (Dataset Preparation)

Do chưa có sẵn dữ liệu, quá trình sẽ bao gồm việc cung cấp script tải dataset PlantVillage, sau đó tổ chức thành:

  • backend/dataset/train
  • backend/dataset/val

2. Tạo File Ánh xạ (Class Mapping)

Agent sẽ tự động sinh file JSON/Dict ánh xạ 38 loại bệnh từ ID của PlantVillage sang tên tiếng Việt thân thiện kèm theo lời khuyên chăm sóc cho từng loại bệnh (ví dụ: Bệnh sương mai, Đốm vi khuẩn, Khỏe mạnh...).

3. Huấn luyện Mô hình (Model Training)

  • Thực thi file train_mobilenet.py. PyTorch sẽ tự động phát hiện và dùng GPU RTX 3050.
  • Quá trình sẽ tận dụng kiến trúc MobileNetV2, CrossEntropyLoss, Adam Optimizer và Data Augmentation.
  • Kết quả đầu ra là file trọng số: mobilenetv2_plantvillage.pth.

4. Tích hợp Model vào FastAPI (Backend Inference)

Thay thế logic Mock bằng Inference thực sự với PyTorch trong backend/ai_model.py:

  • Khởi tạo kiến trúc models.mobilenet_v2() và thay đổi lớp classifier cuối cùng cho 38 classes.
  • Nạp trọng số từ file mobilenetv2_plantvillage.pth.
  • Áp dụng luồng xử lý ảnh tương đương với tập validation lúc training (Resize -> CenterCrop -> ToTensor -> Normalize).
  • Dự đoán và trả kết quả dự đoán kèm mức độ tin cậy.

5. Kế hoạch Kiểm thử (Verification Plan)

  • Automated: Gửi request POST lên endpoint /predict bằng một vài ảnh mẫu qua curl hoặc Python script.
  • Manual: Sử dụng giao diện Swagger UI (http://localhost:8000/docs) tải ảnh thật và kiểm tra bằng mắt thường.
