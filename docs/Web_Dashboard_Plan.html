Phase 2 — ESP32-CAM Integration

Kết nối phần cứng thật sau khi Phase 1 hoàn thành và ổn định.

Phase 2 sẽ thực hiện sau khi Phase 1 test ổn định. Bao gồm:
  • ESP32 Firmware (Arduino/PlatformIO): MJPEG streaming server, HTTP POST sensor data mỗi 30s, nhận lệnh tưới, chụp ảnh theo lịch
  • Phần cứng mở rộng: Thêm DHT22 (nhiệt độ/độ ẩm), BH1750 (ánh sáng), Water Level Sensor vào mạch
  • Backend updates: Thay mock bằng data thật, FCM push khi alert, proxy MJPEG stream
