Kế hoạch Triển khai: Thuật toán AI & Web Demo cho Smart Planter AI

Dựa trên bối cảnh hệ thống và các quyết định kỹ thuật chúng ta đã thống nhất qua quá trình trao đổi, dưới đây là kế hoạch chi tiết để xây dựng thuật toán AI nhận diện bệnh và Web Demo.

Mấu chốt kỹ thuật đã thống nhất

  • Mô hình AI: Phân loại ảnh (Image Classification) bằng kiến trúc MobileNetV2. Huấn luyện thực hiện trên máy khác, máy local chỉ chạy inference.
  • Dữ liệu: Bộ dữ liệu chuẩn PlantVillage.
  • Frontend: React + Vite kết hợp Vanilla CSS (Tập trung vào thẩm mỹ cao, Glassmorphism, Micro-animations, tone màu chủ đạo Emerald + Dark Mode).
  • Backend: Python FastAPI đóng vai trò là API Gateway xử lý ảnh.
  • Workflow: Triển khai toàn bộ luồng Full-stack (Frontend -> Backend -> Mock Model / Pre-trained Model) để thông pipeline.

Chi tiết Triển khai

1. Khởi tạo & Cấu trúc Thư mục Tổng thể

Tạo cấu trúc thư mục rõ ràng phân tách giữa Frontend và Backend trong dự án.

  • NEW backend/: Thư mục chứa mã nguồn Python FastAPI và các script AI.
  • NEW web-demo/: Thư mục chứa ứng dụng React Vite.

2. Backend & AI Pipeline (Python FastAPI)

Chúng ta sẽ dựng một server FastAPI siêu tốc độ, nhận file ảnh gửi lên, tiền xử lý và trả về kết quả chuẩn đoán.

  • NEW backend/requirements.txt: Chứa các thư viện cần thiết: fastapi, uvicorn, python-multipart, Pillow, torch, torchvision, numpy.
  • NEW backend/main.py: Khởi tạo FastAPI app. Cấu hình CORS. Định nghĩa endpoint POST /predict.
  • NEW backend/ai_model.py: Module chứa logic nạp mô hình MobileNetV2. Hàm predict_image() sẽ trả về kết quả (tạm thời sử dụng dữ liệu giả lập cho đến khi nạp model huấn luyện xong).
  • NEW backend/train_mobilenet.py: Script huấn luyện pipeline với PlantVillage dataset. (Script này sẽ được viết sẵn để bạn mang sang máy khác chạy).

3. Frontend Web Demo (React + Vite + Vanilla CSS)

Xây dựng một giao diện Wow cho người dùng, sử dụng Glassmorphism và chuyển động mượt mà.

  • NEW web-demo/package.json & Cấu hình Vite.
  • NEW web-demo/src/index.css: Định nghĩa Design System Dark Mode + Emerald Green, hiệu ứng Glassmorphism.
  • NEW web-demo/src/App.jsx: Layout chính, quản lý State ảnh upload.
  • NEW web-demo/src/components/ImageUploader.jsx: Vùng Drag & Drop tải ảnh lên.
  • NEW web-demo/src/components/PredictionResult.jsx: Thẻ hiển thị kết quả chẩn đoán với hiệu ứng mượt mà.
